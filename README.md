# Мебель AI

Демонстрационная веб-страница редактора контента для интернет-магазина мебели «Рабочее место».

## Как опубликовать на GitHub Pages

1. Создайте публичный репозиторий `mebel-ai`.
2. Загрузите файлы `index.html` и `.nojekyll` в корень репозитория.
3. Откройте `Settings → Pages`.
4. Установите `Deploy from a branch`, затем `main`, `/(root)` и нажмите `Save`.
5. Ссылка появится в разделе Pages после развёртывания.

Страница статическая, поэтому сервер или установка Python не требуются.
Встроены ранее полученные черновики YandexGPT и GigaChat.
Новые запросы к моделям не выполняются.
Яндекс.Метрика не будет собирать данные до установки действующего счётчика.
Не публикуйте API-ключи и персональные данные.
